Privacy Policy

How House Price Prediction handles information across this project.

Information We Collect

Forms on this platform (such as login, registration, property estimation, and contact inquiry) process user inputs on the client side with JavaScript validation. Data stays in your browser session for demo calculations and is not shared with third-party trackers.

How We Use Information

Information submitted through forms is used strictly to:

  • Perform instant machine learning house valuation calculations
  • Demonstrate client-side registration and authentication flows
  • Respond to inquiries and process feedback

Data Security

We implement modern front-end input hygiene, input sanitization, and structured form validation to safeguard application interactions.

Storage & Preferences

We use standard browser localStorage only for preserving your dark/light UI theme preference across page visits, and sessionStorage for passing prediction inputs between pages.

Third-Party Services

Property imagery is delivered by Unsplash CDN, and web fonts are provided by Google Fonts. These assets load securely over HTTPS.

Contact Information

Questions about this policy can be sent to support@houseprediction.com or through the Contact page.
