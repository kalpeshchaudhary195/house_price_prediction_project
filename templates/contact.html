Frequently Asked Questions

How does the prediction work?

You enter details like income, rooms and location, and a Machine Learning regression model trained on housing data estimates the price.

Which dataset is used?

The platform is built around the California Housing Dataset, a well-known dataset for price-prediction tasks.

Is the prediction accurate?

Predictions are estimates for demonstration purposes and should not be treated as a guaranteed market value.

Can I use the website on mobile?

Yes, the entire interface is fully responsive across desktop, tablet and mobile devices.

Does the website store my data?

This is a static HTML/CSS project — forms are validated on the client side and do not persist sensitive data without consent.
